# shahone — Rohail Shah's Developer Portfolio

A responsive, single-page personal portfolio for **Rohail Shah · Web Developer & Programmer**, using a premium black-and-purple visual identity.

## Features
- Premium dark UI with purple gradients and custom CSS illustrations
- Responsive navigation with an accessible mobile menu
- About, skills, featured projects, and contact sections
- Layouts for phones, tablets, and desktops
- Reduced-motion support, semantic sections, SEO/social metadata
- No framework or build step required

## Run locally
Open `index.html` in a browser. Google Fonts are used when online, with system fallbacks.

## Personalize before publishing
- Replace project concepts with real projects and correct repository links.
- Update `hello@rohail.dev` in `index.html` to an email address you actively use.
- Confirm that listed skills and descriptions accurately reflect your experience.
- Adjust the meta description and social metadata if desired.

## Publish with GitHub Pages
1. Open repository **Settings → Pages**.
2. Choose branch `main` and folder `/(root)`.
3. Save and wait for GitHub Pages to publish; the live URL appears in Pages settings.

## Files
- `index.html` — content and metadata
- `style.css` — visual design and responsive styling
- `script.js` — mobile navigation and current year

The repository's existing license file is preserved.
